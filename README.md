# KILLUA-NEW Flutter project

Clean Flutter source project prepared for GitHub/Codemagic. It recreates the benign dashboard/file-manager UI discussed in chat.

The Codemagic workflow creates the missing iOS platform files automatically before building. The workflow currently produces an unsigned IPA; installing a signed IPA on a real iPhone requires Apple code-signing/developer credentials.

This project does not implement exploits, game cheating, bypasses, or unauthorized modification functionality.
